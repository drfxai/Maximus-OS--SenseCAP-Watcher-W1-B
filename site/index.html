MAXIMUS OS

Install on the SenseCAP Watcher W1-B in one click

This installer needs Web Serial. Open this page in Chrome, Edge or Opera on a computer (not Safari, Firefox or a phone).

1 Install the firmware

Plug the Watcher into your computer with a USB-C data cable, then press the button and pick the Watcher's serial port. This writes the bootloader, partition table and Maximus OS in one go, so it also works on a completely erased device. The device is fully erased first, then the new firmware is written. Nothing to download by hand: the firmware is fetched automatically.

Checking the firmware file...

Your browser can't flash over USB. Use Chrome or Edge on a computer. Web Serial needs HTTPS. Open this page from its https:// address.
Nothing shows up in the port list?
  1. Use a USB-C cable that carries data (some charge-only cables don't).
  2. If the device was wiped it may not enumerate by itself: hold the knob while plugging in the cable, then press Install.
  3. On Windows the first time, Windows may need a moment to install the "USB JTAG/serial debug unit" driver.

2 Connect to Wi-Fi and your relay

These settings are sent to the watch over the same cable and stored on the device. Wi-Fi must be 2.4 GHz.

Don't have a relay yet? Do step 3 first: it takes about five minutes and is free.

3 Telegram bot and AI relay

The relay is a small Cloudflare Worker that runs your Telegram bot and the AI assistant. It keeps the bot token off the watch. One-time setup, free tier is enough.

  1. In Telegram, message @BotFather, send /newbot and copy the token it gives you.
  2. Deploy the Worker: Deploy to Cloudflare
    When asked, paste the bot token as TELEGRAM_BOT_TOKEN and pick any long random string as DEVICE_KEY. Prefer the command line? See docs/CLOUDFLARE.md.
  3. Paste the Worker URL and the same device key in step 2 above, then press the button below to register the webhook.
